Optional value, ala Rust's Option<T> (#320): Some carries a value of
type T, None carries nothing. ONE template serves owned payloads
(Option(X)) and borrowed ones (Option(ref X)) via ref-qualified type
arguments; a borrowed Some shares its pointee (the enum does not own
it). Option(ref T) is the shape #321's NULL removal migrates ref
fields and lookup returns onto.
