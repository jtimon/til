    Tuple.push_all_dynamic

    Group
    Core

    #392: append every element of a raw Dynamic array, each pushed AS "Dynamic" -- a word copied, never dereferenced, deleted as a no-op -- so raw pointers keep raw semantics inside the tuple. The ..Dynamic variadic lowering splats an Array(Dynamic) through this; written in til (like Array.concat / Array.to_vec before it) because the desugar runs inside infer_body and a hand-built loop there would carry til_types and ownership no later pass re-checks. arr is borrowed: a splatted array stays usable at the call site.

    func (mut self: Tuple, arr: Array__Dynamic)

    Tuple.expect_type

    Group
    Core

    #392 stage B: panic unless element i really is a want. A Tuple element carries its type, so reading one at a typed binding can be CHECKED -- the gradual-typing bargain, where a lie about a dynamic value fails at runtime instead of quietly reinterpreting bytes (reading an I64 element as a Str used to answer len 0).

    An element tagged "Dynamic" is exempt: that tag means a raw word -- a C pointer, a #302 raw allocation, a splatted Array(Dynamic) element -- whose reinterpretation is the caller's business and always was. Dynamic means you are on your own, and this keeps it so.

    A typed read reaches this through get_checked below; calling it by hand, ahead of an unchecked read, reads the same way.

    loc is #281's trailing-__LOC__ parameter: it resolves at the CALL SITE, so the panic names the line that read the element wrong. Without it every one of these reported src/core/tuple.til, where nothing is wrong -- and the whole point of the check is to send the reader to the read.

    func (self: Tuple, shallow i: U64, want: Str, loc: Str)

    Tuple.get_checked

    Group
    Core

    #392 stage B: get with the READ's static type in hand. A typed binding (`ref a : I64 = t.get(0)`) lowers to this, so the read is checked against what the element actually is instead of reinterpreting its bytes. expect_type decides; see it for why a "Dynamic" element is exempt. loc is forwarded rather than defaulted again, so the panic names the READ, not this line.

    func (self: Tuple, i: U64, want: Str, loc: Str) returns ref Dynamic
