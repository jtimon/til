    /// its `_fi < len()` termination test already proves the index in

    /// owned. Throws OutOfBounds if `i` is past the end; call as
    /// `arr[i] = val` (or `arr.set(i, own val)!`) to panic on a bad index.
    func set(self: Array__USize, shallow i: USize, own val: USize, mut _err_kind: I64)
    func delete(own self: Array__USize, shallow call_free: Bool)
    /// #342: a fresh Array holding `self`'s elements followed by `other`'s.
    /// Both sources keep theirs -- every element is cloned, exactly as
