    repl_ansi_feed

    Feed one event to the decoder. Returns a normalized key, or REPL_KEY_PENDING when more bytes are needed to decide. An unknown or unsupported sequence is consumed WHOLE and reported as REPL_KEY_UNKNOWN, so no escape byte can ever reach the source buffer.

    func (mut d: AnsiDecoder, shallow ev: I64) returns shallow I64

    repl_ansi_timeout

    No follow-up byte arrived within the ESC timeout. A bare ESC is the Escape key; a truncated sequence is unknown input, never source.

    func (mut d: AnsiDecoder) returns shallow I64

    repl_editor_history_serialize

    One newline-terminated PHYSICAL line per record. Entries cannot contain CR or LF (they are single physical lines), so no escaping and no second representation is needed.

    func (ed: ReplEditor) returns Str

    repl_editor_history_load_str

    Parse a history file. A single trailing CR is stripped so a file written on Windows loads unchanged elsewhere.

    func (mut ed: ReplEditor, data: Str)

    repl_editor_history_add

    Record one ACCEPTED physical line. Empty lines and consecutive duplicates are ignored. Called the moment Enter accepts a line -- before parsing or evaluation -- so a syntax error or a typed exit(0) is still remembered.

    proc (mut ed: ReplEditor, line: Str)

    repl_editor_apply_key

    Apply one normalized key to the editor state. Deliberately free of terminal I/O: the whole state machine is exercised by test/repl_editor.til without a terminal.

    func (mut ed: ReplEditor, shallow key: I64) returns EditAction

    repl_editor_viewport

    Slide the horizontal viewport until cursor is visible in avail input columns, returning the new leftmost byte. Split out of the renderer so the scrolling arithmetic is testable at narrow widths without a terminal.

    func (shallow view_start: USize, shallow cursor: USize, shallow line_len: USize, shallow avail: USize) returns shallow USize

    repl_editor_start

    Decide once, at REPL startup, whether this process edits interactively, and load the history file if it does. Redirect either standard stream (or set TERM=dumb) and nothing here touches the terminal or the disk.

    proc (mut ed: ReplEditor)

    repl_editor_read_line

    Read one PHYSICAL line with editing and history. eof distinguishes end of input from an empty line, exactly as in_read_line's Bool does. Terminal mode is entered here and left before returning, so nothing the REPL evaluates inherits raw console settings.

    proc (mut ed: ReplEditor, prompt: Str, mut eof: Bool) returns Str
