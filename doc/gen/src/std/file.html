    File.readfile

    Group
    Standard library

    Read the entire file at path into a Str. Exits with an error if the file cannot be opened.

    proc (path: Str) returns Str

    File.writefile

    Group
    Standard library

    Write content to the file at path, replacing any previous contents. Exits with an error if the file cannot be opened.

    proc (path: Str, content: Str)

    File.appendfile

    Group
    Standard library

    Append content to the file at path, keeping what is already there. The file is created when it does not exist.

    proc (path: Str, content: Str)

    File.remove

    Group
    Standard library

    Delete the file at path, like rm. Removing a file the process still has open is allowed on POSIX (the handle keeps working until it is closed); a missing path is not an error. Directories are not removed -- pointing this at one is an error.

    proc (path: Str)

    File.exists

    Group
    Standard library

    True when path names an existing directory entry. A directory, or a file the process has no permission to read, still exists.

    proc (path: Str) returns shallow Bool

    File.is_dir

    Group
    Standard library

    True when path names a directory. False for a regular file, and false for a path that does not exist -- "is a directory" is one question, "exists" is another, and File.exists answers that one.

    proc (path: Str) returns shallow Bool

    File.is_file

    Group
    Standard library

    True when path names a regular file -- not a directory, and not a device, fifo or socket either.

    proc (path: Str) returns shallow Bool

    File.remove_tree

    Group
    Standard library

    Remove path and everything under it, like rm -rf: a file, or a directory with its whole subtree. A path that does not exist is already removed and reports success; a symlink is unlinked, never followed. Any other failure is fatal.

    proc (path: Str)

    File.rename

    Group
    Standard library

    Move src onto dst, replacing whatever dst was. On POSIX the replacement is atomic, which is what makes it safe to build a new executable beside the running one and swap it in. Fatal on failure -- notably when the two paths are on different file systems, where a rename cannot happen and a copy is the answer.

    proc (src: Str, dst: Str)

    File.new

    Group
    Standard library

    Open a file at path for reading or writing.

    proc (path: Str, is_write: Bool) returns File

    File.update

    Group
    Standard library

    Open a file at path for in-place update: reads and writes are both allowed and the cursor can be moved with seek, so small regions can be patched without rewriting the whole file. The file must already exist.

    proc (path: Str) returns File

    File.append

    Group
    Standard library

    Open a file at path for appending: writes always land at the end and existing contents are kept, where File.new(path, true) truncates. The file is created when it does not exist. Reads are rejected, and seek does not move where a write lands -- "ab" appends regardless of the cursor.

    proc (path: Str) returns File

    File.write

    Group
    Standard library

    Write a string to the file and return self so writes chain via UFCS: f.write("a").write("b").write("c"). Panics unless opened for writing or update.

    proc (self: File, s: Str) returns ref File

    File.read_all

    Group
    Standard library

    Read the entire file contents into a Str. Panics if opened write-only.

    proc (self: File) returns Str

    File.read

    Group
    Standard library

    Read up to count bytes starting at the current cursor position and advance the cursor. The result is shorter than count near end-of-file. Panics if opened write-only.

    proc (self: File, shallow count: I64) returns Str

    File.tell

    Group
    Standard library

    Return the current cursor position as a byte offset from the start of the file.

    proc (self: File) returns shallow I64

    File.seek

    Group
    Standard library

    Move the cursor to an absolute byte offset from the start of the file. Returns self so calls chain via UFCS.

    proc (self: File, pos: I64) returns ref File

    File.seek_cur

    Group
    Standard library

    Move the cursor by delta bytes relative to its current position (delta may be negative). Returns self so calls chain via UFCS.

    proc (self: File, delta: I64) returns ref File

    File.seek_end

    Group
    Standard library

    Move the cursor to delta bytes relative to the end of the file (delta is typically <= 0). ~f.seek_end(0)~ followed by ~f.tell()~ yields the file size. Returns self so calls chain via UFCS.

    proc (self: File, delta: I64) returns ref File

    File.close

    Group
    Standard library

    Close the underlying file handle. Private: invoked only from delete, which the garbager inserts after a File local's last use, so nothing reads the handle afterwards.

    func (self: File)

    File.delete

    Group
    Standard library

    Release the File: close the handle, then free the struct shell unless the caller still owns it (call_free = false for a stack/value local). The garbager inserts this call right after the File's last use.

    func (own self: File, shallow call_free: Bool)

    Dir.open

    Group
    Standard library

    Start reading the directory at path. Exits with an error if it cannot be opened.

    proc (path: Str) returns Dir

    Dir.next

    Group
    Standard library

    The next entry's name (not its path), "" once every entry has been reported. "." and ".." are never returned. The order is whatever the file system gives -- sort if you need a stable one.

    proc (self: Dir) returns Str

    Dir.list

    Group
    Standard library

    Every entry in the directory at path, in file-system order. The whole listing at once, for callers that want to sort or filter it rather than stream it.

    proc (path: Str) returns Vec__Str
