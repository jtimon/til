    DynVec.with_capacity

    Group
    Standard library

    Create an empty DynVec with room for n elements, so filling it with n items reallocs zero times (Vec.with_capacity's counterpart; the element type is a runtime argument here, as for new).

    func (T: Type, n: U64) returns DynVec

    DynVec.new_like

    Group
    Standard library

    Create an empty DynVec with room for n elements, taking its element metadata from a container that already has it instead of from a Type or a type name. DynArray.to_vec is why this exists: a DynArray carries the element size / kind / clone / delete fns but not the type name new_type_name wants, and a DynVec record can only be built directly inside this file.

    func (elem_size: U64, elem_kind: U64, elem_clone: CloneFn, elem_delete: DeleteFn, n: U64) returns DynVec

    DynVec.append

    Group
    Standard library

    Consume the contents of other by appending them to self. other is taken by ownership and will be empty after the call.

    func (mut self: DynVec, own other: DynVec)

    DynVec.move_from

    Group
    Standard library

    Replace self's contents with other's via memcpy (no per-elem clone). Avoids the Vec_clone + extra Vec_delete that plain self = other emits. Takes mut (not own) so caller retains ownership of other; its natural scope-end auto-delete frees other.data. Setting other.count = 0 prevents that auto-delete from re-running elem_delete on items whose bytes were moved into self.

    func (mut self: DynVec, mut other: DynVec)

    DynVec.move_to

    Group
    Standard library

    Give self's contents to dest, which drops whatever it held. Vec.move_to's counterpart, and the argument-flipped spelling of dest.move_from(self). Both sides are mut here rather than one of them own, because the values these moves exist for are struct FIELDS, and a field cannot be an owned argument or receiver.

    func (mut self: DynVec, mut dest: DynVec)

    DynVec.unsafe_get

    Group
    Standard library

    Unchecked ref to the element at index i. Caller guarantees i < self.count; bypasses get's throwing bounds check. for-in and the DynMap binary search use this directly (issue #284/#287).

    func (self: DynVec, i: U64) returns ref Dynamic

    Group

    Return a reference to the element at index i. Throws OutOfBounds if i is past the end; call as vec[i] to panic on a bad index. The reference is valid until the next mutation.

    func (self: DynVec, i: U64) returns ref Dynamic throws OutOfBounds

    DynVec.truncate

    Group
    Standard library

    Drop the elements from index n to the end and set count to n (the survivors [0, n) are left untouched). Panics if n exceeds len. Vec.truncate's counterpart.

    func (mut self: DynVec, n: U64)

    DynVec.take_prefix

    Group
    Standard library

    Split off the first n elements into a new DynVec. Panics if n exceeds self.len(). The remaining elements shift to the front.

    func (mut self: DynVec, n: U64) returns DynVec

    DynVec.take

    Group
    Standard library

    Take the contents out: the returned DynVec holds self's elements and self is left empty. Vec.take hands its BUFFER over and blanks itself; a DynVec cannot, because elem_size/elem_kind/elem_clone/ elem_delete are runtime values rather than type parameters, and a blanked DynVec would no longer know how to grow or free itself. The elements move as bytes into a fresh buffer instead -- which is take_prefix of the whole vec.

    func (mut self: DynVec) returns DynVec

    DynVec.unsafe_set

    Group
    Standard library

    Overwrite the element at index i without a bounds check, dropping the old value. Caller guarantees i < self.count; the write-side mirror of unsafe_get (issue #284).

    func (mut self: DynVec, i: U64, own val: Dynamic)

    DynVec.set

    Group
    Standard library

    Overwrite the element at index i. val is owned. Throws OutOfBounds if i is past the end; call as dynvec[i] = val (or dynvec.set(i, own val)!) to panic on a bad index.

    func (mut self: DynVec, i: U64, own val: Dynamic) throws OutOfBounds

    DynVec.push_take

    Group
    Standard library

    Move bytes of src[i] into self (push). Source slot is zeroed so that src's eventual elem_delete on it is a no-op (relies on the same count0/dataNULL convention used by take_children and DynVec.delete).

    func (mut self: DynVec, mut src: DynVec, i: U64)
