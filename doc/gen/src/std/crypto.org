* schnorr_sign
:PROPERTIES:
:CUSTOM_ID: til.src.std.crypto.schnorr_sign
:group: Standard library
:END:

Sign the 32-byte ~msg~ with ~seckey~ and the caller's 32 bytes of
BIP-340 auxiliary randomness. Hashing a longer message down to
~msg~ and choosing ~aux_rand~ (fresh random bytes, or zeros for a
deterministic signature) are the caller's: this module generates
neither. The signature is verified before it is returned, as
upstream's sign32 does not do that itself.

#+begin_src til
proc schnorr_sign(seckey: U256, msg: U256, aux_rand: U256) returns Signature throws CryptoError
#+end_src

* Array__U32.concat
:PROPERTIES:
:CUSTOM_ID: til.src.std.crypto.Array__U32.concat
:group: Standard library
:END:

#342: a fresh Array holding ~self~'s elements followed by ~other~'s.
Both sources keep theirs -- every element is cloned, exactly as
~clone~ does -- so neither is moved out from under its owner. The
mixed-splat variadic lowering builds its collector with this: the
fixed arguments become one Array, the splatted Array is the other,
and the call is then the pure-splat form the desugar already handles.
