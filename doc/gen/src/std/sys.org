* get_env
:PROPERTIES:
:CUSTOM_ID: til.src.std.sys.get_env
:group: Standard library
:END:

Read an environment variable, "" when unset. NOT view-compatible:
~name~ reaches C as a NUL-terminated string, so it must be a literal
or an owned Str, never a substr view (a view's bytes end at its count,
with no NUL there, and getenv would read past it). Pass
~view.clone()~ at the call site if you have one -- since #343 the
boundary panics on a view here rather than reading past it, but the
caller still owns the choice. The result is owned:
the bytes are copied out of the environ block, so the Str stays valid
however the environment changes later. A host observation, hence proc:
the same call can answer differently twice in one run.

#+begin_src til
proc get_env(name: Str) returns Str
#+end_src

* Cmd
:PROPERTIES:
:CUSTOM_ID: til.src.std.sys.Cmd
:group: Standard library
:END:

A command to run, built from argv elements -- never from shell text.

~system_cmd~ / ~spawn_cmd~ / ~run_cmd~ above hand a STRING to
/bin/sh or cmd.exe, which re-splits it on whitespace, expands $VAR
and globs it; every caller then has to quote its arguments back out
of that, differently per host. A Cmd passes its elements straight to
execvp / CreateProcess, so an argument means exactly the bytes it
holds -- spaces, quotes, dollars and all. A shell is still reachable
by asking for one: ~Cmd.new("sh", "-c", script)~.

Output is inherited by default (the child writes to this process's
stdout/stderr as it goes). ~capture()~ collects it instead, and
~stdout_to~/~stderr_to~ send it to files:

    c := Cmd.new("echo", "a b")
    c.capture()
    if c.run() != 0 { panic("echo failed") }
    print(c.out())

#+begin_src til
struct Cmd {
    ref mut handle : U8
namespace:
    proc new(args: ..Str) returns Cmd
    proc arg(self: Cmd, a: Str) returns ref Cmd
    proc args(self: Cmd, more: ..Str) returns ref Cmd
    proc cwd(self: Cmd, dir: Str) returns ref Cmd
    proc env(self: Cmd, name: Str, value: Str) returns ref Cmd
    proc stdout_to(self: Cmd, path: Str) returns ref Cmd
    proc stderr_to(self: Cmd, path: Str) returns ref Cmd
    proc stderr_to_stdout(self: Cmd) returns ref Cmd
    proc capture(self: Cmd) returns ref Cmd
    proc capture_out(self: Cmd) returns ref Cmd
    proc render(self: Cmd) returns Str
    proc start(self: Cmd) returns shallow I64
    proc wait(self: Cmd) returns shallow I64
    proc poll(self: Cmd) returns shallow Bool
    proc status(self: Cmd) returns shallow I64
    proc run(self: Cmd) returns shallow I64
    proc run_checked(self: Cmd)
    proc out(self: Cmd) returns Str
    proc err(self: Cmd) returns Str
    func close(self: Cmd)
    func delete(own self: Cmd, shallow call_free: Bool)
    func clone(self: Cmd) returns Cmd
    func size() returns shallow USize
}
