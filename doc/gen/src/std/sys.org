* get_env
:PROPERTIES:
:CUSTOM_ID: til.src.std.sys.get_env
:group: Standard library
:END:

Read an environment variable, "" when unset. NOT view-compatible:
`name` reaches C as a NUL-terminated string, so it must be a literal
or an owned Str, never a substr view (a view's bytes end at its count,
with no NUL there, and getenv would read past it). Pass
`view.clone()` at the call site if you have one. The result is owned:
the bytes are copied out of the environ block, so the Str stays valid
however the environment changes later. A host observation, hence proc:
the same call can answer differently twice in one run.

* Cmd
:PROPERTIES:
:CUSTOM_ID: til.src.std.sys.Cmd
:group: Standard library
:END:

A command to run, built from argv elements -- never from shell text.

`system_cmd` / `spawn_cmd` / `run_cmd` above hand a STRING to
/bin/sh or cmd.exe, which re-splits it on whitespace, expands $VAR
and globs it; every caller then has to quote its arguments back out
of that, differently per host. A Cmd passes its elements straight to
execvp / CreateProcess, so an argument means exactly the bytes it
holds -- spaces, quotes, dollars and all. A shell is still reachable
by asking for one: `Cmd.new("sh", "-c", script)`.

Output is inherited by default (the child writes to this process's
stdout/stderr as it goes). `capture()` collects it instead, and
`stdout_to`/`stderr_to` send it to files:

    c := Cmd.new("echo", "a b")
    c.capture()
    if c.run() != 0 { panic("echo failed") }
    print(c.out())

#+begin_src til
struct Cmd {
    ref mut handle : U8
namespace:
    /// A command from its program name and arguments. The program is
    /// looked up in PATH unless the name contains a separator.
    proc new(args: ..Str) returns Cmd
    /// Append one argument. Returns `self` so calls chain via UFCS.
    proc arg(self: Cmd, a: Str) returns ref Cmd
    /// Append several arguments at once.
    proc args(self: Cmd, more: ..Str) returns ref Cmd
    /// Run the command in `dir` instead of this process's working
    /// directory. Only the child moves; this process stays put.
    proc cwd(self: Cmd, dir: Str) returns ref Cmd
    /// Set an environment variable for the child only. The rest of the
    /// environment is inherited; this process's own is never touched.
    proc env(self: Cmd, name: Str, value: Str) returns ref Cmd
    /// Send the child's stdout to `path`, truncating it first.
    proc stdout_to(self: Cmd, path: Str) returns ref Cmd
    /// Send the child's stderr to `path`, truncating it first.
    proc stderr_to(self: Cmd, path: Str) returns ref Cmd
    /// Merge the child's stderr into wherever its stdout goes -- the
    /// `2>&1` of build logs, without a shell.
    proc stderr_to_stdout(self: Cmd) returns ref Cmd
    /// Collect the child's output instead of letting it through, for
    /// reading with `out()` and `err()` once it has finished. The two
    /// streams stay separate; each command captures into its own spool
    /// file, so concurrent captures never mix.
    proc capture(self: Cmd) returns ref Cmd
    /// Collect stdout only, leaving stderr on this process's stderr so
    /// a compiler's diagnostics still reach the terminal live.
    proc capture_out(self: Cmd) returns ref Cmd
    /// The command as a human would type it, for logs and error
    /// messages. NOTHING executes this string -- it is a rendering, not
    /// the command.
    proc render(self: Cmd) returns Str
    /// Start the child without waiting, returning its pid (POSIX) or
    /// process handle (Windows). Pair with `wait` or `poll`.
    proc start(self: Cmd) returns shallow I64
    /// Block until the child finishes and return its status: the exit
    /// code, or MINUS the signal number when a signal killed it (so a
    /// compiler the OOM killer took reads as -9, not as an ordinary
    /// exit 137).
    proc wait(self: Cmd) returns shallow I64
    /// True once the child has finished, false while it is still
    /// running. Deliberately not a status: every I64 is a legal status.
    proc poll(self: Cmd) returns shallow Bool
    /// The status of a child that has already finished. Use after
    /// `poll` reports true; `wait` returns the same value directly.
    proc status(self: Cmd) returns shallow I64
    /// Start the command and block until it finishes, returning its
    /// status. The lower-level runner: a non-zero status is a value
    /// here, not a failure. Use `run_checked` when it is one.
    proc run(self: Cmd) returns shallow I64
    /// Run the command, printing it first, and stop the program if it
    /// fails. The build-script runner: what ran is visible in the log
    /// and a failure is reported at the command that caused it, with
    /// its exact status, instead of surfacing later as a missing file.
    proc run_checked(self: Cmd)
    /// The child's captured stdout. Requires `capture()` (or
    /// `capture_out()`) before the run, and a finished child.
    proc out(self: Cmd) returns Str
    /// The child's captured stderr. Requires `capture()` before the
    /// run, and a finished child.
    proc err(self: Cmd) returns Str
    /// Release the command. A child still running is waited for first:
    /// dropping it would leave a process nobody reaps.
    func close(self: Cmd)
    func delete(own self: Cmd, shallow call_free: Bool)
    func clone(self: Cmd) returns Cmd
    func size() returns shallow USize
}
