* DynArray.concat
:PROPERTIES:
:CUSTOM_ID: til.src.std.dyn_array.DynArray.concat
:group: Standard library
:END:

A fresh DynArray holding ~self~'s elements followed by ~other~'s.
Both sources keep theirs -- every element is cloned, exactly as
~clone~ does. Array.concat's counterpart; the element type is
runtime data here, so mismatched operands panic instead of being
rejected by the typer.

#+begin_src til
func DynArray.concat(self: DynArray, other: DynArray) returns DynArray
#+end_src
