    get_env

    Group
    Standard library

    Read an environment variable, "" when unset. NOT view-compatible: name reaches C as a NUL-terminated string, so it must be a literal or an owned Str, never a substr view (a view's bytes end at its count, with no NUL there, and getenv would read past it). Pass view.clone() at the call site if you have one -- since #343 the boundary panics on a view here rather than reading past it, but the caller still owns the choice. The result is owned: the bytes are copied out of the environ block, so the Str stays valid however the environment changes later. A host observation, hence proc: the same call can answer differently twice in one run.

    proc (name: Str) returns Str

    Cmd

    Group
    Standard library

    A command to run, built from argv elements -- never from shell text.

    system_cmd / spawn_cmd / run_cmd above hand a STRING to /bin/sh or cmd.exe, which re-splits it on whitespace, expands $VAR and globs it; every caller then has to quote its arguments back out of that, differently per host. A Cmd passes its elements straight to execvp / CreateProcess, so an argument means exactly the bytes it holds -- spaces, quotes, dollars and all. A shell is still reachable by asking for one: Cmd.new("sh", "-c", script).

    Output is inherited by default (the child writes to this process's stdout/stderr as it goes). capture() collects it instead, and stdout_to/stderr_to send it to files:

    c := Cmd.new("echo", "a b") c.capture() if c.run() != 0 { panic("echo failed") } print(c.out())

    Cmd.poll

    Cmd.status

    Cmd.run

    Group
    Standard library

    Start the command and block until it finishes, returning its status. The lower-level runner: a non-zero status is a value here, not a failure. Use run_checked when it is one.

    proc (self: Cmd) returns shallow I64

    Cmd.run_checked

    Group
    Standard library

    Run the command, printing it first, and stop the program if it fails. The build-script runner: what ran is visible in the log and a failure is reported at the command that caused it, with its exact status, instead of surfacing later as a missing file.

    proc (self: Cmd)
