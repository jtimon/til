* DynHashMap.with_capacity
:PROPERTIES:
:CUSTOM_ID: til.src.std.dyn_hashmap.DynHashMap.with_capacity
:group: Standard library
:END:

Create an empty DynHashMap pre-sized for ~n~ entries
(HashMap.with_capacity's counterpart; the key/value types are
runtime arguments here, as for ~new~). Sizes the dense
keys/values/nexts arrays and grows the bucket array by doubling
until ~n~ fits under the 0.75 load factor, so inserting up to ~n~
never rehashes.

#+begin_src til
func DynHashMap.with_capacity(K: Type, V: Type, n: U64) returns DynHashMap
#+end_src

Deep copy. Cloning the dense keys/values/nexts vecs and the
bucket array preserves every chain link, so the copy needs no
rehash (DynMap.clone's counterpart).
