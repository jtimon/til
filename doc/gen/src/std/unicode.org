:PROPERTIES:
:CUSTOM_ID: til.src.std.unicode.grapheme_floor
:group: Standard library
:END:

Boundary at or before a byte position, clamped to len. Accepts positions

#+begin_src til

#+end_src

* grapheme_previous
:PROPERTIES:
:CUSTOM_ID: til.src.std.unicode.grapheme_previous
:group: Standard library
:END:

Boundary strictly before a byte position (<= len), or zero at the start.
Accepts interior positions. Linear in the logical line, not constant-time
character indexing; forward scans should use grapheme_next.

#+begin_src til
func grapheme_previous(text: Str, position: U64) returns U64
#+end_src

:group: Standard library

Boundary at or after a byte position, clamped to len. Same scan complexity

#+begin_src til

:CUSTOM_ID: til.src.std.unicode.grapheme_count
:group: Standard library
:END:

Number of graphemes in [start, end). Both offsets must be boundaries in

#+end_src
