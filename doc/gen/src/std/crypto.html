    schnorr_sign

    Group
    Standard library

    Sign the 32-byte msg with seckey and the caller's 32 bytes of BIP-340 auxiliary randomness. Hashing a longer message down to msg and choosing aux_rand (fresh random bytes, or zeros for a deterministic signature) are the caller's: this module generates neither. The signature is verified before it is returned, as upstream's sign32 does not do that itself.

    proc (seckey: U256, msg: U256, aux_rand: U256) returns Signature throws CryptoError

    schnorr_verify

    Group
    Standard library

    Whether sig is a valid BIP-340 signature of the 32-byte msg under the serialized x-only pubkey. A public key that is not on the curve throws; a bad signature is a plain false.

    proc (pubkey: U256, msg: U256, sig: Signature) returns Bool throws CryptoError

    Array__U32.concat

    Group
    Standard library

    #342: a fresh Array holding self's elements followed by other's. Both sources keep theirs -- every element is cloned, exactly as clone does -- so neither is moved out from under its owner. The mixed-splat variadic lowering builds its collector with this: the fixed arguments become one Array, the splatted Array is the other, and the call is then the pure-splat form the desugar already handles.

    func (self: Array__U32, other: Array__U32) returns Array__U32

    Array__U32.to_vec

    Group
    Standard library

    #342: a fresh Vec holding a clone of every element, self intact. The vec(T, x, ..arr) lowering ends here: a splat's length is a runtime value, so the literal's block is folded into one Array with concat and converted, instead of the desugar hand-building a push loop whose nodes no later pass would infer.

    func (self: Array__U32) returns Vec__U32
