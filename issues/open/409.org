** WIP #409 CPU SIMD feature targeting and performance validation

Follow up [[../fixed/318.org][#318]] with explicit CPU-feature targeting and
measurements of useful vector loops. Ordinary til SIMD remains CPU code;
choosing an ISA is not choosing a GPU or enabling automatic offload.

*** Scope

- Model the compilation target's enabled CPU features separately from its
  OS/architecture. Keep conservative baseline builds reproducible; do not
  silently select the build host's ISA or introduce runtime dispatch.
- Make ~simd_width(T)~ agree with the enabled features and C compiler flags.
  It reports a recommended fixed lane count, not a guarantee of one machine
  instruction per operation. Scalable SVE/RVV lengths need a separate design.
- Measure array arithmetic, loads/stores, comparisons, selection and
  reductions on x86-64 and AArch64. Include short inputs, tails, unaligned
  starts, widths below/above a register and data sets larger than cache.
- Compare scalar and explicit-SIMD implementations with identical numerical
  semantics. Inspect assembly to distinguish vector instructions, scalarized
  operations, copying at storage boundaries and call overhead. Record CPU,
  compiler version, flags, timing method and results, including regressions.

*** Proposed sequence and acceptance

First establish measurements using the existing toolchains and artifacts.
Then propose a target-feature representation and its user-facing selection
syntax for approval before implementation. The proposal must name any new
flags/configuration, their readers, cross-compilation behavior and installation
requirements; no feature database, cache or manifest is pre-approved here.

Acceptance: selected features consistently control emitted code and width
queries; baseline binaries do not require optional instructions; cross-builds
do not consult host CPUID; semantic tests match the interpreter; and reported
performance is supported by reproducible measurements. No universal speedup
or cross-architecture bit identity beyond the language contract is promised.

Independent of [[./317.org][#317]] (MLIR). Coordinate operation coverage with
[[./410.org][#410]]; explicit device execution is tracked by [[./411.org][#411]]
and its prototype by [[./412.org][#412]].

*** U32 vector-accumulator experiment (master 2ccf1d159)

Completed the requested algorithm comparison using existing til operations.
Keeping sums in vectors helps optimized code, but four accumulators are a
tuning choice, not a universal replacement. This experiment adds no compiler
rewrite or public reduction API. Floating-point reduction order is unchanged;
the other #409 controls and native ARM timing remain outstanding.

**** Algorithms and exactness

Compared checked/unchecked scalar loops with three SIMD forms at widths
2, 4, 8 and 16:

- ~block~: reduce each loaded vector, then add its scalar sum, as in the
  earlier benchmark.
- ~one~: accumulate loaded vectors lane-wise, then perform one final
  ~reduce_add~ and a scalar tail.
- ~four~: unroll by four vectors with four independent accumulators; finish
  remaining whole vectors in the first accumulator, combine the four vectors,
  then perform one final ~reduce_add~ and a scalar tail. This changes both
  accumulator count AND loop unrolling; the measurements do not isolate those
  two effects from one another.

All additions are U32 modulo 2^32. For M=2^32,
~((x mod M) + (y mod M)) mod M = (x+y) mod M~, so regrouping across lanes,
blocks and accumulators preserves every result, including overflow. This
argument does not apply to floating-point sums; no automatic FP reassociation
is proposed.

**** Method and validation

Same Ryzen 9950X3D/CPU-0 affinity and tool versions as the earlier phases.
GCC 13.3 and Clang 18.1.3 at O2, with baseline/x86-64-v3/x86-64-v4; GCC O0
small cases as a separate unoptimized comparison. No LTO or fast-math.
Timed N=17/start=1, N=4096/start=0 and 1, and N=33554432/start=1 (128 MiB,
larger than CPU 0's 96 MiB L3). Allocation and verification are untimed.

The harness calls generated til functions through volatile function pointers
and consumes results in a volatile sink. Each variant is calibrated to at
least 50 ms per batch; use the median of five batch means. Variant order
rotates between rounds. First Clang v4 and GCC O0 runs showed large timing
spread and were repeated with identical binaries; the tables use those repeat
runs. Raw initial and repeat logs were retained under tmp/. No system or
frequency settings were changed, and small timing differences are not claims
of statistical significance.

Correctness passed for every compiled configuration, also with native
ASAN+UBSAN and AArch64 GCC -O2 under QEMU. Four input patterns cover zero,
all U32.MAX, alternating 0x7fffffff/0x80000000, and deterministic nonlinear
full-width values. Lengths 0,1,2,3,4,5,7,8,9,15,16,17,31,32,33,63,64,65,
127,128,129 are checked at offsets 0 and 1. Each result equals a U64 reference
sum narrowed once to U32, and input storage is checked unchanged after each
call. The tested maximum length cannot overflow the U64 reference.

Interpreter/native CLI output matched at lengths 0,1,3,4,5,17,31,32,33,63,64,
65,127,128,129; an ASAN interpreter run at 129 matched too. For example, all
fourteen kernels and the reference produced 1707816393 for the hashed input
at length 129/start=1. No native AArch64 performance was measured.

**** Assembly and recommendation

- GCC baseline width-4/one keeps an XMM accumulator with ~paddd~ in the
  vector loop; horizontal ~pshufd~/add operations occur after that loop.
  Width-4/four keeps four independent XMM accumulators on its successful hot
  path, then combines/reduces them once. Bounds and error paths remain.
- GCC baseline width-8/four retains calls to ~Simd__U32_n1_8_load~ and spills
  accumulator halves to the stack around them. That concrete code-generation
  cost accompanies its regression; do not prescribe more accumulators merely
  because the source exposes more independent additions.
- AArch64 GCC emits NEON ~add v*.4s~, but its width-4/one loop still packs
  scalar GPR lanes into a vector and extracts them back each iteration.
  Successful vector instruction selection is not proof that the accumulator
  remains efficiently resident in vector registers on every target.
- Recommend the one-accumulator pattern as the simple optimized-U32 starting
  point; select width/unrolling only after measuring the compiler, ISA and
  input sizes that matter. Four is useful in the demonstrated GCC width-4 and
  AVX2-width cases, not a universal default. Keep scalar comparisons enabled,
  since Clang already produces excellent vector reductions from scalar loops.

This completes the requested experiment. Further implementation work remains
the already-proposed CPU/optimization controls (approval pending), option-aware
freshness (#406), and real ARM measurements. The remaining wide-wrapper
inlining/register-representation costs are documented rather than hidden by
blanket always_inline or changes to floating-point semantics.

***** Reduction kernel source

#+begin_src til
mode cli

sum_checked := func(a: Array(U32), start: USize, n: USize) returns U32 {
    mut sum : U32 = 0
    for i in 0..n { sum = sum + a.get(start + i)! }
    return sum
}

sum_unchecked := func(a: Array(U32), start: USize, n: USize) returns U32 {
    mut sum : U32 = 0
    for i in 0..n { sum = sum + a.unsafe_get(start + i) }
    return sum
}

sum_block := macro(N: I64) returns FuncDef {
return func(a: Array(U32), start: USize, n: USize) returns U32 {
    width := Simd(U32, N).zero().len()
    bulk := n - n.mod(width)
    mut sum : U32 = 0
    mut i : USize = 0
    while i < bulk {
        sum = sum + Simd(U32, N).load(a, start + i)!.reduce_add()
        i = i + width
    }
    while i < n { sum = sum + a.unsafe_get(start + i); i++ }
    return sum
}
}

sum_one := macro(N: I64) returns FuncDef {
return func(a: Array(U32), start: USize, n: USize) returns U32 {
    width := Simd(U32, N).zero().len()
    bulk := n - n.mod(width)
    mut accum := Simd(U32, N).zero()
    mut i : USize = 0
    while i < bulk {
        accum = accum + Simd(U32, N).load(a, start + i)!
        i = i + width
    }
    mut sum := accum.reduce_add()
    while i < n { sum = sum + a.unsafe_get(start + i); i++ }
    return sum
}
}

sum_four := macro(N: I64) returns FuncDef {
return func(a: Array(U32), start: USize, n: USize) returns U32 {
    width := Simd(U32, N).zero().len()
    group := width * 4
    bulk4 := n - n.mod(group)
    bulk := n - n.mod(width)
    mut a0 := Simd(U32, N).zero()
    mut a1 := Simd(U32, N).zero()
    mut a2 := Simd(U32, N).zero()
    mut a3 := Simd(U32, N).zero()
    mut i : USize = 0
    while i < bulk4 {
        a0 = a0 + Simd(U32, N).load(a, start + i)!
        a1 = a1 + Simd(U32, N).load(a, start + i + width)!
        a2 = a2 + Simd(U32, N).load(a, start + i + width * 2)!
        a3 = a3 + Simd(U32, N).load(a, start + i + width * 3)!
        i = i + group
    }
    while i < bulk {
        a0 = a0 + Simd(U32, N).load(a, start + i)!
        i = i + width
    }
    mut sum := ((a0 + a1) + (a2 + a3)).reduce_add()
    while i < n { sum = sum + a.unsafe_get(start + i); i++ }
    return sum
}
}

main := proc(size: I64) {
    n := size.to_usize()
    mut values := Array(U32).new(n + 2)
    for i in 0..(n + 2) {
        mut word := i.to_u32().mul(1664525).add(1013904223)
        word = word.bxor(word.shr(16)).mul(2246822519)
        word = word.bxor(word.shr(13))
        values.set(i, own word)!
    }
    mut expected : U64 = 0
    for i in 0..n { expected = expected + values.get(i + 1)!.cast(U64) }
    println("expected ", expected.to_u32())
    println(sum_checked(values, 1, n), " ", sum_unchecked(values, 1, n))
    println(sum_block(2)(values, 1, n), " ", sum_block(4)(values, 1, n), " ",
        sum_block(8)(values, 1, n), " ", sum_block(16)(values, 1, n))
    println(sum_one(2)(values, 1, n), " ", sum_one(4)(values, 1, n), " ",
        sum_one(8)(values, 1, n), " ", sum_one(16)(values, 1, n))
    println(sum_four(2)(values, 1, n), " ", sum_four(4)(values, 1, n), " ",
        sum_four(8)(values, 1, n), " ", sum_four(16)(values, 1, n))
}

#+begin_src c
#define main til_reduction_original_main
#ifndef REDUCE409_SOURCE
#define REDUCE409_SOURCE "reduce409.c"
#endif
#include REDUCE409_SOURCE
#undef main
#include <stdint.h>
#include <time.h>

typedef U32 (*sum_fn)(Array__U32 *, U64, U64);
struct kernel { const char *name; int width; sum_fn fn; };
static const struct kernel kernels[] = {
    {"checked", 1, sum_checked}, {"unchecked", 1, sum_unchecked},
    {"block", 2, sum_block__n1_2}, {"block", 4, sum_block__n1_4},
    {"block", 8, sum_block__n1_8}, {"block", 16, sum_block__n2_16},
    {"one", 2, sum_one__n1_2}, {"one", 4, sum_one__n1_4},
    {"one", 8, sum_one__n1_8}, {"one", 16, sum_one__n2_16},
    {"four", 2, sum_four__n1_2}, {"four", 4, sum_four__n1_4},
    {"four", 8, sum_four__n1_8}, {"four", 16, sum_four__n2_16}
};
enum { KERNELS = sizeof(kernels) / sizeof(*kernels), SAMPLES = 5 };
static volatile U32 sink;

static uint64_t now_ns(void) {
    struct timespec t;
    if (clock_gettime(CLOCK_MONOTONIC_RAW, &t)) { perror("clock"); exit(1); }
    return (uint64_t)t.tv_sec * 1000000000 + t.tv_nsec;
}
static double run(sum_fn fn, Array__U32 *a, U64 start, U64 n, uint64_t reps) {
    sum_fn volatile call = fn;
    uint64_t t = now_ns();
    for (uint64_t i = 0; i < reps; ++i) { sink = call(a, start, n); }
    return (double)(now_ns() - t) / reps;
}
static int compare_double(const void *a, const void *b) {
    double x = *(const double *)a, y = *(const double *)b;
    return (x > y) - (x < y);
}
static U32 pattern(U64 i, int kind) {
    if (kind == 0) { return 0; }
    if (kind == 1) { return UINT32_MAX; }
    if (kind == 2) { return i & 1 ? 0x80000000U : 0x7fffffffU; }
    U32 word = (U32)i * 1664525U + 1013904223U;
    word = (word ^ (word >> 16)) * 2246822519U;
    return word ^ (word >> 13);
}
static void verify(Array__U32 *a, U64 start, U64 n, int kind) {
    uint64_t wide = 0;
    for (U64 i = start; i < start + n; ++i) { wide += ((U32 *)a->data)[i]; }
    U32 expected = (U32)wide;
    for (int k = 0; k < KERNELS; ++k) {
        U32 got = kernels[k].fn(a, start, n);
        if (got != expected) {
            fprintf(stderr, "mismatch %s/%d n=%llu start=%llu pattern=%d got=%u expected=%u\n",
                kernels[k].name, kernels[k].width, n, start, kind, got, expected);
            exit(1);
        }
        for (U64 i = 0; i < a->cap; ++i) {
            if (((U32 *)a->data)[i] != pattern(i, kind)) {
                fprintf(stderr, "input changed by %s/%d\n", kernels[k].name, kernels[k].width);
                exit(1);
            }
        }
    }
}
int main(int argc, char **argv) {
    int check_only = argc > 1 && !strcmp(argv[1], "check");
    int small_only = argc > 1 && !strcmp(argv[1], "small");
    U64 capacity = check_only || small_only ? 4128 : 33554464;
    size_t bytes = ((size_t)capacity * sizeof(U32) + 63) & ~(size_t)63;
    Array__U32 a = {(U8 *)aligned_alloc(64, bytes), capacity};
    if (!a.data) { perror("allocation"); return 1; }
    Array__U32 small = {a.data, 160};
    const U64 lengths[] = {0,1,2,3,4,5,7,8,9,15,16,17,31,32,33,63,64,65,127,128,129};
    for (int p = 0; p < 4; ++p) {
        for (U64 i = 0; i < small.cap; ++i) { ((U32 *)small.data)[i] = pattern(i, p); }
        for (size_t i = 0; i < sizeof(lengths) / sizeof(*lengths); ++i) {
            verify(&small, 0, lengths[i], p);
            verify(&small, 1, lengths[i], p);
        }
    }
    if (!check_only) {
        for (U64 i = 0; i < capacity; ++i) { ((U32 *)a.data)[i] = pattern(i, 3); }
        const U64 lengths2[] = {17,4096,4096,33554432};
        const U64 starts[] = {1,0,1,1};
        puts("variant,width,n,start,ns_per_element,vs_checked,min_ns,max_ns,repetitions");
        for (int c = 0; c < (small_only ? 3 : 4); ++c) {
            U64 n = lengths2[c], start = starts[c];
            Array__U32 slice = {a.data, n + 2};
            verify(&slice, start, n, 3);
            uint64_t reps[KERNELS];
            double samples[KERNELS][SAMPLES];
            for (int k = 0; k < KERNELS; ++k) {
                reps[k] = 1;
                while (run(kernels[k].fn, &a, start, n, reps[k]) * reps[k] < 50000000.0) {
                    reps[k] *= 2;
                }
            }
            for (int r = 0; r < SAMPLES; ++r) {
                for (int j = 0; j < KERNELS; ++j) {
                    int k = (j + r * 5) % KERNELS;
                    samples[k][r] = run(kernels[k].fn, &a, start, n, reps[k]);
                }
            }
            for (int k = 0; k < KERNELS; ++k) { qsort(samples[k], SAMPLES, sizeof(double), compare_double); }
            for (int k = 0; k < KERNELS; ++k) {
                printf("%s,%d,%llu,%llu,%.6f,%.3f,%.0f,%.0f,%llu\n",
                    kernels[k].name, kernels[k].width, n, start, samples[k][2] / n,
                    samples[0][2] / samples[k][2], samples[k][0], samples[k][SAMPLES-1],
                    (unsigned long long)reps[k]);
            }
            fflush(stdout);
        }
    }
    puts("correctness: passed");
    free(a.data);
    return 0;
}

*** Load/store lowering follow-up (implemented on master 183169265)

Completed the measured memory-path optimization. The method signatures,
scalar-aligned layout, checked-access contract and CPU/optimization defaults
are unchanged. CPU profile controls, option-aware freshness and native ARM
timing remain outstanding; this issue stays WIP.

**** Changes and correctness

- Generated load/store bodies copy exactly N scalar lanes with one constant-
  size memcpy. This replaces N scalar get/dereference operations and the
  private per-lane store helper. Both backends execute the same generated
  checks; no C-only substitute implementation or always_inline attribute.
- Check ~start <= count && count - start >= N~, with short-circuit evaluation,
  before computing byte addresses or copying. Return on success and throw
  OutOfBounds LAST, following Array.get's existing structure. The old two
  early throws made the throws pass insert repeated error-slot tests around
  the remaining operations, inflating the inlining cost.
- The typer recognizes compiler-verified SIMD storage as byte-copyable even
  though the type has a generated outer-shell delete. This exemption is based
  on SIMD metadata, not its name; copying managed records is still rejected.
- An overlapping-source regression exposed a pre-existing interpreter
  discrepancy: shallow SIMD parameters borrowed the caller's storage instead
  of taking C's by-value snapshot. Fixed parameter marshalling for named,
  reference-result and unboxed Dynamic SIMD arguments. This fixes mutations
  through another argument as well as overlapping stores; merely replacing
  memcpy with memmove would not fix that value-semantics bug.
- Testing two-byte lanes exposed another existing generator defect: I16/U16
  have no scalar bnot method, so their SIMD definitions failed to type-check.
  Vector complement now uses the existing vector xor primitive and an
  all-ones splat. No new scalar methods were introduced.

Regression coverage in ~test/simd.til~:

- ~test_simd_memory_lane_sizes~: all eleven scalar lane types, widths from
  1 to 32, scalar-aligned offsets, guards and independent copies; also checks
  I16/U16 complement values.
- ~test_simd_memory_bounds_matrix~: empty/short/exact-size arrays, starts at
  zero, one, the end and USize.MAX; failed stores leave every element intact.
- ~test_simd_memory_float_bits~: preserves negative-zero, NaN payload,
  negative-infinity and ordinary F32 bits through load/store.
- ~test_simd_memory_argument_evaluation~: arguments evaluate once on success
  and failure, including temporary source arrays and vector receivers.
- ~test_simd_memory_overlapping_source~ and
  ~test_simd_memory_parameter_snapshot~: borrowed vector sources remain value
  snapshots when the destination overlaps or the function mutates the source.

Verification: ~make clean && make test~ passed 493/493, including ASAN,
self-translation and the existing managed-memcpy rejection checks. The SIMD
suite passed 21/21 interpreted and compiled under ASAN, 21/21 with Clang -O2,
and 21/21 in an AArch64 GCC -O2 build run through QEMU. The scratch benchmark's
correctness matrix also passed all native configurations below and AArch64
emulation. Native ARM performance is still unmeasured.

**** Code-generation findings and next optimization work

- Ordinary ~compile_c~ currently adds ~-g~ and warnings, but NO optimization
  level. Treat O0 and optimized builds separately; SIMD instructions alone
  do not compensate for unoptimized wrappers and copying.
- GCC O2 baseline ~add_vector__n1_4~ contains two calls to
  ~Simd__F32_n1_4_load~ per iteration, return-value register/stack transfers,
  error-kind/bounds checks, then ~addps~ and ~movups~. The add is vectorized;
  the surrounding memory path is expensive. GCC O3 inlines those calls and
  improves this kernel from 1.4001 to 0.3281 ns/element, but scalar lane loads,
  per-lane null checks and register packing still remain.
- GCC's baseline scalar add loop uses ~addss~. Clang auto-vectorizes the
  unchecked scalar map loops, and even its checked U32 reduction: comparing
  against "scalar source" does not mean comparing against scalar instructions.
- x86-64-v3 emits YMM ~vaddps~ for width 8 and splits width 16 across YMM
  operations. v4 emits ZMM ~vaddps~ for width 16. Wider instructions are real,
  but the tables show they do not automatically improve these complete loops.
- AArch64 ~-march=armv8-a~ emits NEON ~fadd v0.4s, ...~ at width 4, two
  four-lane additions at width 8 and four at width 16. The full small-case
  correctness matrix passed QEMU; no native ARM timing was collected.
- Next internal work: lower checked contiguous SIMD loads/stores so successful
  accesses do not require N independent scalar dereferences and aggregate-call
  round trips. Preserve the bounds/throw contract, including no partial writes;
  do not remove checks merely because a benchmark's input is valid. Measure
  inlining/code-size tradeoffs instead of imposing blanket always_inline.
- Also measure a U32 vector-accumulator reduction with one final horizontal
  reduction. The present per-block reduction has a scalar accumulation chain;
  it is not evidence that all SIMD reduction algorithms are slower. Do not
  apply that reassociation to floating sums with the fixed-tree contract.

*** Proposed controls (approval required before implementation)

One explicit CPU profile, separate from Target's OS/architecture:

- ~--cpu=baseline|x86-64-v3|x86-64-v4~. Default remains baseline; no ~native~,
  host CPUID probing, runtime dispatch or per-chip tuning in the first version.
- Resolve profile and target together in ~src/self/targets.til~ to ONE in-memory
  result containing C compiler flags and recommended SIMD bits. Stamp the
  existing Context width fact from that same result before type expansion.
- Baseline x86-64/AArch64 stays 128 bits; x86 v3 selects 256 and v4 selects
  512. Thus F32 queries give 4/8/16 respectively. These are predictable profile
  defaults, not measured optimal widths for every loop. Explicit Simd widths

  compile-time width/type decisions without executing host CPUID. GPU execution

behavior. It controls optimization only, never fast-math or implicit FMA.
Interpretation does not optimize native user code; translation alone has no C

options embedded in the existing compiler override; document that precedence.

#+begin_src til
mode cli

F2 := Simd(F32, 2)
F4 := Simd(F32, 4)
F8 := Simd(F32, 8)
F16 := Simd(F32, 16)
U2 := Simd(U32, 2)
U4 := Simd(U32, 4)
U8V := Simd(U32, 8)
U16V := Simd(U32, 16)

write_value := func(mut dest: F32, value: F32) { dest = value }

add_checked := func(a: Array(F32), b: Array(F32), mut output: Array(F32), start: USize, n: USize) {
    for i in 0..n {
        pos := start + i
        value := a.get(pos)! + b.get(pos)!
        output.set(pos, own value)!
    }
}

select_checked := func(a: Array(F32), b: Array(F32), mut output: Array(F32), start: USize, n: USize) {
    for i in 0..n {
        pos := start + i
        x := a.get(pos)!.clone()
        y := b.get(pos)!.clone()
        mut value := y
        if x > y { value = x }
        output.set(pos, own value)!
    }
}

reduce_checked := func(a: Array(U32), start: USize, n: USize) returns U32 {
    mut sum : U32 = 0
    for i in 0..n { sum = sum + a.get(start + i)! }
    return sum
}

add_scalar := func(a: Array(F32), b: Array(F32), mut output: Array(F32), start: USize, n: USize) {
    for i in 0..n {
        pos := start + i
        write_value(output.unsafe_get(pos), a.unsafe_get(pos) + b.unsafe_get(pos))
    }
}

select_scalar := func(a: Array(F32), b: Array(F32), mut output: Array(F32), start: USize, n: USize) {
    for i in 0..n {
        pos := start + i
        x := a.unsafe_get(pos).clone()
        y := b.unsafe_get(pos).clone()
        mut value := y
        if x > y { value = x }
        write_value(output.unsafe_get(pos), value)
    }
}

add_vector := macro(N: I64) returns FuncDef {
return func(a: Array(F32), b: Array(F32), mut output: Array(F32), start: USize, n: USize) {
    width := Simd(F32, N).zero().len()
    bulk := n - n.mod(width)
    mut i : USize = 0
    while i < bulk {
        value := Simd(F32, N).load(a, start + i)! + Simd(F32, N).load(b, start + i)!
        value.store(output, start + i)!
        i = i + width
    }
    while i < n {
        pos := start + i
        write_value(output.unsafe_get(pos), a.unsafe_get(pos) + b.unsafe_get(pos))
        i++
    }
}
}

select_vector := macro(N: I64) returns FuncDef {
return func(a: Array(F32), b: Array(F32), mut output: Array(F32), start: USize, n: USize) {
    width := Simd(F32, N).zero().len()
    bulk := n - n.mod(width)
    mut i : USize = 0
    while i < bulk {
        x := Simd(F32, N).load(a, start + i)!
        y := Simd(F32, N).load(b, start + i)!
        value := (x > y).select(x, y)
        value.store(output, start + i)!
        i = i + width
    }
    if i < n { select_scalar(a, b, output, start + i, n - i) }
}
}

reduce_scalar := func(a: Array(U32), start: USize, n: USize) returns U32 {
    mut sum : U32 = 0
    for i in 0..n { sum = sum + a.unsafe_get(start + i) }
    return sum
}

reduce_vector := macro(N: I64) returns FuncDef {
return func(a: Array(U32), start: USize, n: USize) returns U32 {
    width := Simd(U32, N).zero().len()
    bulk := n - n.mod(width)
    mut sum : U32 = 0
    mut i : USize = 0
    while i < bulk {
        sum = sum + Simd(U32, N).load(a, start + i)!.reduce_add()
        i = i + width
    }
    while i < n { sum = sum + a.unsafe_get(start + i); i++ }
    return sum
}
}

main := proc(size: I64) {
    n := size.to_usize()
    mut a := Array(F32).new(n + 2)
    mut b := Array(F32).new(n + 2)
    mut output := Array(F32).new(n + 2)
    mut ints := Array(U32).new(n + 2)
    for i in 0..(n + 2) {
        a.set(i, own F32.from_i64(i.to_i64().mod(16) - 8))!
        b.set(i, own F32.from_i64(i.to_i64().mod(7)))!
        ints.set(i, own i.to_u32())!
    }
    add_checked(a, b, output, 1, n)
    select_checked(a, b, output, 1, n)
    println("checked ", reduce_checked(ints, 1, n))
    add_scalar(a, b, output, 1, n)
    add_vector(2)(a, b, output, 1, n)
    add_vector(4)(a, b, output, 1, n)
    add_vector(8)(a, b, output, 1, n)
    add_vector(16)(a, b, output, 1, n)
    select_scalar(a, b, output, 1, n)
    select_vector(2)(a, b, output, 1, n)
    select_vector(4)(a, b, output, 1, n)
    select_vector(8)(a, b, output, 1, n)
    select_vector(16)(a, b, output, 1, n)
    println(reduce_scalar(ints, 1, n), " ", reduce_vector(2)(ints, 1, n), " ",

}

#+begin_src c
#define main til_benchmark_original_main
#ifndef SIMD409_SOURCE
#define SIMD409_SOURCE "simd409.c"
#endif
#include SIMD409_SOURCE
#undef main
#include <stdint.h>
#include <time.h>
#include <math.h>

typedef void (*map_fn)(Array__F32 *, Array__F32 *, Array__F32 *, U64, U64);
typedef U32 (*sum_fn)(Array__U32 *, U64, U64);
static map_fn const adds[] = {add_checked, add_scalar, add_vector__n1_2,
    add_vector__n1_4, add_vector__n1_8, add_vector__n2_16};
static map_fn const selects[] = {select_checked, select_scalar, select_vector__n1_2,
    select_vector__n1_4, select_vector__n1_8, select_vector__n2_16};
static sum_fn const sums[] = {reduce_checked, reduce_scalar, reduce_vector__n1_2,
    reduce_vector__n1_4, reduce_vector__n1_8, reduce_vector__n2_16};
static const int widths[] = {1, 1, 2, 4, 8, 16};
static const char *const variants[] = {"checked", "unchecked", "simd2", "simd4", "simd8", "simd16"};
static volatile U32 sink;

static uint64_t now_ns(void) {
    struct timespec t;
    if (clock_gettime(CLOCK_MONOTONIC_RAW, &t)) { perror("clock_gettime"); exit(1); }
    return (uint64_t)t.tv_sec * 1000000000 + t.tv_nsec;
}

static double run_map(map_fn fn, Array__F32 *a, Array__F32 *b,
                      Array__F32 *out, U64 start, U64 n, uint64_t repetitions) {
    map_fn volatile call = fn; /* Keep repeated calls observable to the compiler. */
    uint64_t t = now_ns();
    for (uint64_t i = 0; i < repetitions; ++i) { call(a, b, out, start, n); }
    return (double)(now_ns() - t) / repetitions;
}

static double run_sum(sum_fn fn, Array__U32 *a, U64 start, U64 n,
                      uint64_t repetitions) {
    sum_fn volatile call = fn;
    uint64_t t = now_ns();
    for (uint64_t i = 0; i < repetitions; ++i) { sink = call(a, start, n); }
    return (double)(now_ns() - t) / repetitions;
}

static int compare_double(const void *a, const void *b) {
    double x = *(const double *)a, y = *(const double *)b;
    return (x > y) - (x < y);
}

static void verify(Array__F32 *a, Array__F32 *b, Array__F32 *out,
                   Array__U32 *ints, U64 start, U64 n) {
    float *x = (float *)a->data, *y = (float *)b->data, *z = (float *)out->data;
    U32 expected_sum = 0;
    for (U64 i = start; i < start + n; ++i) { expected_sum += ((U32 *)ints->data)[i]; }
    for (int k = 0; k < 6; ++k) {
        for (int op = 0; op < 2; ++op) {
            for (U64 i = 0; i < out->cap; ++i) { z[i] = -999.0f; }
            (op ? selects[k] : adds[k])(a, b, out, start, n);
            for (U64 i = 0; i < out->cap; ++i) {
                float expected = -999.0f;
                if (i >= start && i < start + n) {
                    expected = op ? (x[i] > y[i] ? x[i] : y[i]) : x[i] + y[i];
                }
                if (memcmp(&z[i], &expected, sizeof(float))) {
                    fprintf(stderr, "mismatch op=%d width=%d n=%llu start=%llu i=%llu\n",
                            op, widths[k], n, start, i);
                    exit(1);
                }
            }
        }
        if (sums[k](ints, start, n) != expected_sum) {
            fprintf(stderr, "reduction mismatch width=%d n=%llu\n", widths[k], n);
            exit(1);
        }
    }
}

int main(int argc, char **argv) {
    int check_only = argc > 1 && !strcmp(argv[1], "check");
    int small_only = argc > 1 && !strcmp(argv[1], "small");
    U64 capacity = check_only || small_only ? 4128 : 33554464;
    size_t bytes = ((size_t)capacity * sizeof(float) + 63) & ~(size_t)63;
    Array__F32 a = {(U8 *)aligned_alloc(64, bytes), capacity};
    Array__F32 b = {(U8 *)aligned_alloc(64, bytes), capacity};
    Array__F32 out = {(U8 *)aligned_alloc(64, bytes), capacity};
    Array__U32 ints = {(U8 *)aligned_alloc(64, bytes), capacity};
    if (!a.data || !b.data || !out.data || !ints.data) { perror("allocation"); return 1; }
    for (U64 i = 0; i < capacity; ++i) {
        ((float *)a.data)[i] = (float)((int)(i % 16) - 8) * 0.125f;
        ((float *)b.data)[i] = (float)(i % 7) * 0.25f;
        ((float *)out.data)[i] = 0;
        ((U32 *)ints.data)[i] = (U32)(i % 32);
    }
    /* Keep small-case checking independent of the timed working-set size. */
    Array__F32 ca = {a.data, 64}, cb = {b.data, 64}, co = {out.data, 64};
    Array__U32 ci = {ints.data, 64};
    const U64 checks[] = {0, 1, 2, 3, 4, 5, 7, 8, 9, 15, 16, 17, 31, 32, 33};
    for (size_t i = 0; i < sizeof(checks) / sizeof(*checks); ++i) {
        verify(&ca, &cb, &co, &ci, 0, checks[i]);
        verify(&ca, &cb, &co, &ci, 1, checks[i]);
    }
    if (!check_only) {
        const U64 sizes[] = {17, 4096, 4096, 33554432};
        const U64 starts[] = {1, 0, 1, 1};
        puts("op,n,start,variant,width,ns_per_element,speedup,min_ns,max_ns,repetitions");
        for (int c = 0; c < (small_only ? 3 : 4); ++c) {
            U64 n = sizes[c], start = starts[c];
            /* Validate the full timed range and guard elements before timing. */
            Array__F32 va = {a.data, n + 2}, vb = {b.data, n + 2}, vo = {out.data, n + 2};
            Array__U32 vi = {ints.data, n + 2};
            verify(&va, &vb, &vo, &vi, start, n);
            for (int op = 0; op < 3; ++op) {
                double baseline = 0;
                for (int k = 0; k < 6; ++k) {
                    uint64_t repetitions = 1;
                    double elapsed;
                    do {
                        elapsed = op == 2 ? run_sum(sums[k], &ints, start, n, repetitions)
                            : run_map(op ? selects[k] : adds[k], &a, &b, &out, start, n, repetitions);
                        if (elapsed * repetitions >= 50000000.0) { break; }
                        repetitions *= 2;
                    } while (repetitions < (1ULL << 32));
                    double samples[3];
                    for (int r = 0; r < 3; ++r) {
                        samples[r] = op == 2 ? run_sum(sums[k], &ints, start, n, repetitions)
                            : run_map(op ? selects[k] : adds[k], &a, &b, &out, start, n, repetitions);
                    }
                    qsort(samples, 3, sizeof(double), compare_double);
                    if (!k) { baseline = samples[1]; }
                    printf("%s,%llu,%llu,%s,%d,%.6f,%.3f,%.0f,%.0f,%llu\n",
                           op == 0 ? "add" : op == 1 ? "select" : "reduce",
                           n, start, variants[k], widths[k], samples[1] / n, baseline / samples[1],
                           samples[0], samples[2], (unsigned long long)repetitions);
                    fflush(stdout);
                }
            }
        }
    }
    puts("correctness: passed");
    free(a.data); free(b.data); free(out.data); free(ints.data);
    return 0;
}
