** OPEN #464 Restore ASAN as the default of make test (temporarily off since #313)

TEMPORARY state, introduced on purpose: ~make test~ (and ~make test_two_pass~,
which the merge script runs for "Two-pass: " commits) runs the suite WITHOUT
ASAN. With the cage (#313) the sanitizer's bookkeeping became the dominant
cost of every merge-time run (the historical "self-asan" series against
"self"), and the merge loop needed the time back while #313's follow-ups
settle (the one-flag layout, doc/self.org "Decided: one layout flag").

What is lost meanwhile, locally: ASAN's heap and stack checks on the compiler
and on every compiled test program, and the cage's exit-time leak report
(test/leak_report.til and the other rows gated on the ASAN run are skipped).
CI keeps all of it: the linux-x64 and linux-arm64 native jobs run
~make test_asan~, and the opt-out suites build ASAN compilers as before.

*** Complete temporary shutdown

The default used to retain hidden sanitizer work despite selecting the
native suite. It now performs every ordinary functional/layout check without
sanitizer instrumentation:

- ~make.til::layout_regressions(b, false)~ uses ~bin/til~ for compile-time
  folding and compact-to-native self-translation. It neither builds nor
  invokes ~bin/til_asan~ / ~tmp/til_usize32_asan~. Explicit ~test_asan~ and
  ~check_usize64~ select ~layout_regressions(b, true)~ and retain that work.
- ~src/tests.til~ passes its explicit ASAN selection to nested drivers:
  ~install_tilvm.til~ / ~install_tilvm_native.til~ hosts and native libraries,
  ~type_arg_qualifiers.til~ child runs, ~numeric_cast_errors.til~ reference
  builds, ~library_namespace.til~'s enum consumer and Linux JNI pass, and
  ~jni.til~'s Linux JNI pass. The ordinary JVM runs and text checks remain.
- HolyC support/primitives/numeric-cast C reference rows use the suite flag
  rather than hard-coding ~--asan~. Their width and optimization matrices
  and exact diagnostic comparisons remain unchanged.
- Standalone driver commands accept a trailing ~--asan~ after their existing
  arguments (VM: fixture/action; qualifiers: compiler/family; cast errors:
  width; JNI/namespaces: alongside ~--no-jvm~). The suite supplies this only
  in explicit ASAN mode. The separate optional MLIR and TempleOS integration
  drivers retain their existing sanitizer checks; they are outside ~make test~.

*** Self-translation data

The default also used to translate twice through the same ~bin/til~, with one
native result mislabeled as ASAN. It now runs only the native benchmark and
boot comparison. A different selected compiler still gets its independent
self-application/repeatability guard (~self_check~), including ASAN and the
native-layout opt-out; it is not recorded as a benchmark series.

The ~self-asan~ curve and summary measurement are removed. CSV columns 15-16
(~self_asan_ms~, ~self_asan_mem~) remain in place to preserve historical data;
new rows leave them empty, including explicit ASAN runs. Native measurements
remain in columns 18-19 (~self_ms~, ~self_mem~). Do not delete/relabel old
values or populate the archive with native timings/zeroes. ~8981d947b~ documents
the original in-place ASAN column rename. Plotting accepts empty cells as
absent, rather than treating them as measured zeroes.
