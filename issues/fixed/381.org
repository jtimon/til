declaration order by exposing every generated method name's fixed return type

focused diagnostic.

while the exact typer-error count drops from latest master's 230 to 228: two
field defaults exercised the same secondary-comparison path. The
~generated_default_method_error~ harness assertion pins the focused diagnostic
to exactly one occurrence.
