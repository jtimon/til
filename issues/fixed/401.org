*** Post-mortem

The plotter encoded the totals.csv schema directly in its row type, parser,
series lookup, colors, axes, and labels. It now treats CSV headers as opaque
column names and receives each series' column, display label, and axis through
~--series~, with independent axis-unit and divisor options. A follow-up added
configurable axis rounding precision and moved unit labels horizontally above
the axes. ~src/tests.til~ owns the special totals configuration and requests
seconds for time and GB for memory. Totals uses exact maxima from its selected
ten rows and suffixes units on each tick (including fractional labels such as
~9.5 gb~); other callers retain configurable rounded maxima.
Solid time lines make their movement easy to follow, while dashed memory lines
remain distinguishable where independently scaled series coincide. Both Y axes
show five labelled positions with short outward tick marks.

The suite now records ~peak_mem~, the maximum sampled sum of all active
non-self process-tree RSS, alongside the existing per-phase peak sums. Missing
trailing columns in historical CSV rows are skipped rather than plotted as
zeroes. ~self_ms~ / ~self_mem~ now measure only ~self_translate~; ~gc_audit~
belongs to the build category instead of polluting the compiler benchmark.

Regression test: the plot test in ~src/tests.til~ plots unrelated ~requests~
and ~heap_bytes~ columns, verifies that an unselected column is absent, and
checks both divisors, configurable precision, horizontal units, and axis dash
styling, plus five tick marks on each Y axis. It also covers suffix units,
fractional ticks, and a selected column absent from an older row.

~examples/plot.til~ was nominally a CSV chart generator, but it hardcoded the
totals.csv schema, series names, colors, two-axis assignment, and memory
units. This prevented other CSV data from using the example without modifying
its source.
