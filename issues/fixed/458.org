Utf8Read result. Str's fields, ownership/view rules, byte operations and c_str

grapheme_next/previous/floor/ceil/count/offset names and byte-offset/complexity

terminal UTF-8 adapters delegate to Str while cell-width policy stays in
libterminal. That consumer migration is committed in Tiled as 94d6724 and
tracked in its fixed #15.

*** Focused navigation contracts

After the split merged as =cc3fdd85c=, the user requested lower interpretation
and memory totals, including removal of redundant tests. The three jobs each
loaded and compiled the same property tables and scanned the whole corpus.
Within each selected case, floor/ceil at every byte and count/offset checks
repeated segmentation that the next/previous boundary checks already covered.

All 766 official cases remain, with every expected boundary checked forward
and backward. The parser also checks that the first/last expected boundaries
span the entire input. The per-byte navigation cross-product is replaced by
an independent, literal-offset mixed-document fixture: ASCII, a combining
sequence, emoji ZWJ, CRLF and LF, three regional indicators, a malformed UTF-8
prefix followed by a combining mark, a stray continuation byte and a lone CR.
Every byte still gets floor/ceil/previous assertions in this fixture. Additional
contracts cover EOF, out-of-range clamping, nonzero subranges, empty ranges,
offset indices, counts and byte preservation. In particular, previous at an
interior position and nonzero subranges were absent from the old corpus loop.

*** UTF-8 primitive optimization

On base =4859f9e8d=, measured the encoder and decoder separately before retaining
each change. =Str.from_codepoint= now allocates one NUL-terminated buffer and
fills its bytes, rather than allocating one Str per byte plus format's variadic
array and final buffer. =Str.read_utf8= uses the stored byte count and checks
the remaining view length before unchecked reads, avoiding repeated len/get
dispatch and duplicate bounds checks. Scalar validation, maximal malformed
prefixes, streaming behavior and the Str representation are unchanged.

=test/utf8.til= adds independent expected bytes for the existing scalar boundary
cases and checks the trailing NUL, so mutually wrong encoder/decoder results
cannot pass by round-trip agreement. Existing streaming/truncated/view and
malformed-input tests pass, as do all 766 grapheme cases in both backends.

The temporary benchmark =tmp/utf8_perf.til= uses twelve mixed-width scalars,
including NUL and the scalar range boundaries. Each run verifies byte counts
and decoded checksums. All variants used the same compiler binary
(=bin/til_asan=, revision =cc3fdd85c=); native builds used =--asan= and the default
optimization level. Interpreted runs use 1,000 repetitions (12,000 scalars),
native runs 1,000,000 (12,000,000 scalars). Runs are sequential and memory-limited.

| Measurement                        | Original | Optimized |
|------------------------------------+----------+-----------|
| Interpreted encoding, two-run mean  | 29.240 s |   6.321 s |
| Interpreted decoding, two-run mean  | 10.483 s |   9.118 s |
| Native encoding, three-pair median |  7.856 s |   1.820 s |
| Native decoding, three-pair median |  0.912 s |   0.542 s |
| Full Unicode interpretation, mean  | 35.087 s |  30.153 s |

Encoding alone measured 6.349 s interpreted / 1.701 s native, with the decoder
unchanged, and 31.001 s for the Unicode test. The subsequent decoder change
