** FIXED #458 Extract Tiled Unicode primitives into core Str and std

Added core Str.from_codepoint, read_utf8 and is_valid_utf8 with the separate
Utf8Read result. Str's fields, ownership/view rules, byte operations and c_str
interop are unchanged. No new string representation is introduced.

Moved Unicode 17.0 grapheme segmentation into std/unicode, with explicit
grapheme_next/previous/floor/ceil/count/offset names and byte-offset/complexity
contracts. The property data, Unicode license, generator and all 766 official
grapheme cases now live in Til. The existing recursive SDK installation carries
the module/data/license. The Tiled #15 migration uses the core/std API; its
terminal UTF-8 adapters delegate to Str while cell-width policy stays in
libterminal. That consumer migration is committed in Tiled as 94d6724 and
tracked in its fixed #15.

*** Controlled performance follow-up

Rebased the unmerged extraction onto =d78924826=. The user disabled other
sessions for these measurements. Every isolated run used the same ASAN compiler
(=0.0.1-d78924826=), full original corpus, all 766 cases and all boundary/offset
assertions. Temporary =clock_ms()= probes separated input preparation from
assertions; =/usr/bin/time= measured the whole invocation. The probes were
removed before the final suite. Commands ran sequentially in a 64 GiB scope.

| Cumulative change                   | Preparation | Assertions | Whole invocation |
|-------------------------------------+-------------+------------+------------------|
| Original extraction, first run      |    115.02 s |   105.23 s |         230.05 s |
| Line views, markers, hex and append |     26.00 s |   101.65 s |         136.96 s |
| Avoid repeated floor/ceil scans     |     25.72 s |    75.44 s |         110.27 s |
| Lazy segmentation state and ASCII  |     26.13 s |    68.23 s |          96.82 s |
| Token views instead of split       |     19.76 s |    68.16 s |          90.36 s |
| Original extraction, repeat        |    113.50 s |   104.67 s |         228.05 s |
| All changes, repeat                |     19.76 s |    68.43 s |          90.61 s |

The repeated end-to-end means are 229.05 s versus 90.49 s (about 60.5% less
time). These are isolated interpreted-conformance results, not whole-suite or
application speedups. Logs: =tmp/unicode-perf-baseline-{1,2}.log=,
=tmp/unicode-perf-parser-3.log=, =tmp/unicode-perf-boundaries-1.log=,
=tmp/unicode-perf-segmentation-1.log=, =tmp/unicode-perf-token-spans-1.log=,
and =tmp/unicode-perf-optimized-2.log=.

Preparation walks borrowed line/token views, ignores comment tails, reuses the
two marker strings, parses hexadecimal digits directly, and appends into one
preallocated string per case. The official corpus and generated tables remain
unchanged. Floor/ceil return the known end boundary directly; ceil retains the
cluster end from its first scan. Segmentation decides a break before computing
unused next-state properties and handles ASCII controls/pairs and end-of-input
without table lookups. Full UAX #29 state still handles non-ASCII continuations.
