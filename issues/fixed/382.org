** FIXED #382 Add concise construction of Some borrowed refs

*** Post-mortem

Constructing a non-null borrowed Option repeated its complete destination type
because generic return-only type materialization could not infer nested
generated names such as ~Option__ref_T~, and borrow summaries did not preserve
the source through omitted generic calls.

~safe_ref(value)~ now infers ~Option(ref T)~, preserves the source borrow and
lifetime, and rejects local borrow escapes through wrappers. The final migration
replaces explicit construction expressions throughout source and tests while
retaining constructor patterns, explanatory examples, and the direct-constructor
diagnostic control.

Regression: ~test_safe_ref_infers_borrowed_option~,
~test_safe_ref_materializes_unannotated_option~,
~test_safe_ref_extends_source_lifetime~, and ~test_safe_ref_forward_summary~
cover inference, late materialization, lifetime extension, and forwarded borrow
identity. ~make clean && make test~ passes 416/416.

Til forbids NULL refs, so wrapping an existing ref in an Option is always a
safe conversion. The current spelling repeats the complete destination type:

#+begin_src til
Option(ref TypeScope).Some(scope)
#+end_src

This is correct but noisy, and the pattern is not specific to TypeScope. Add a
generic concise spelling, provisionally ~safe_ref(scope)~, equivalent to
~Option(ref T).Some(scope)~ for any ~ref T~.

The design should:

- infer ~T~ from the argument without repeating the payload type;
- preserve the exact borrowed ref and its lifetime, with no clone, move, or
  ownership change;
- reject values that are not refs rather than introducing a nullable fallback;
- work in returns, arguments, assignments, and aggregate initializers; and
- choose a name that describes the operation clearly. ~safe_ref~ emphasizes
  that the source ref cannot be NULL; ~some_ref~ may more directly describe
  construction of the Option.

After choosing the spelling, replace the verbose generic pattern throughout
the codebase and add focused Option(ref T) coverage.
